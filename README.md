# Caleb Tesho Student Portfolio

This is a personal portfolio website built with plain HTML5, CSS, and JavaScript. It presents information about the student, their hobbies, learning plan, photo gallery, media content, project skills, and a contact form.

## Website purpose

The site is designed to share a student profile in a clean, readable, and responsive format while demonstrating multiple front-end web skills. The project focuses on accessible structure, easy-to-read typography, effective spacing, and simple interactive elements.

## JavaScript features included

1. Form validation
   - Checks that the name, email, and message are filled in.
   - Rejects invalid email formats.
   - Shows a browser-only success message after validation.

2. Image gallery navigation
   - Lets the user move between photos with Previous and Next buttons.
   - Updates the image, alt text, caption, and photo counter.

3. Mobile navigation toggle
   - Shows or hides the navigation menu on small screens.
   - Keeps the mobile menu accessible and tidy.

4. Dark mode toggle
   - Switches the website between light and dark themes.
   - Saves the selected theme in localStorage for the current browser.

## How to test locally

1. Open the project folder in VS Code.
2. Run a local preview extension such as Live Server.
3. Open the generated local address for the project, usually something like http://localhost:5500 or http://localhost:8000.
4. Check the following:
   - index.html loads correctly
   - CSS styling is applied
   - JavaScript runs without console errors
   - gallery buttons work
   - form validation works
   - mobile menu works
   - dark mode toggle works
   - media files load and play correctly

## Sources used

- W3Schools HTML and CSS tutorials for web structure and styling reference.
- Local media assets, photographs, and audio/video files stored in the project folders.
- Classroom guidance on semantic HTML, accessibility, and responsive design.

## Render deployment

Create a Static Site connected to this repository and select the `main` branch. Leave Root Directory blank, use `echo "No build required"` as the Build Command, set Publish Directory to `.`, and enable Auto Deploy. The site is plain HTML, CSS, and JavaScript, so no build step is needed.
